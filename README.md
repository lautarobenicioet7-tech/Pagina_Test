Pagina_Test

Descripción del proyecto

Este proyecto consiste en el desarrollo de una página web para poner en práctica conocimientos de programación y desarrollo web. En él se trabaja con diferentes herramientas que permiten crear la parte visual de la página, procesar información y guardar datos en una base de datos.

Herramientas utilizadas

HTML: se utiliza para organizar el contenido de la página web, como los títulos, los textos, las imágenes y los enlaces.

CSS: permite modificar la apariencia de la página, por ejemplo, los colores, los tamaños de letra, los márgenes y la ubicación de los elementos.

PHP: es un lenguaje de programación que se utiliza para procesar información del lado del servidor y conectar la página web con la base de datos.

MySQL: se utiliza para crear y administrar la base de datos, donde se puede guardar, consultar y modificar información.

XAMPP: es un programa que permite ejecutar un servidor web local en la computadora. Incluye herramientas como Apache y MariaDB, que es compatible con MySQL, para poder probar la página y trabajar con la base de datos sin necesidad de publicarla en internet.


Objetivo del proyecto

El objetivo es aprender a desarrollar una página web utilizando distintas herramientas de programación y bases de datos. También se busca comprender cómo se relacionan el diseño de una página, el código PHP y la base de datos para que la aplicación pueda funcionar correctamente.
